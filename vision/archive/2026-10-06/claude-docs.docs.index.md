# docs/

## Summary

The system's docs for people: plain, book-like, readable by someone who is not technical, with no reference numbers or codes. Today it holds the README, everything about the project in one read, and the vision, what we are building and why. The architecture, the glossary, the file tree and the other docs are added one at a time as each is written for people; until then their notes stay in `agents/system/docs/`. The knowledge base agent writes each with its own skill, and the owner can edit them on the page. The lower levels get the same folder when their docs are written.
